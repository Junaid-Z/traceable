## 🌟 Features

- **Real-time Custody Tracking:** See exactly which employee or department currently holds an asset.
- **Check-in / Check-out System:** Log asset transfers with timestamps.
- **Audit History:** Full chronological log of every person who has possessed an asset over its lifecycle.
- **Search & Filters:** Instantly search by asset ID, serial number, tag, status, or current holder.
- **Role-Based Access Control (RBAC):** Admin control for managing assets and read-only views for staff.
